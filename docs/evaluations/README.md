# Detector evaluations

This directory contains reviewed, small, reproducible evaluation records that
are worth keeping in Git: manifests, labels, detector output, and reports.
Large source recordings and generated review media belong in the ignored
`artifacts/runs/` tree.

Each evaluation directory should describe its source recording and preserve
the detector revision and hashes needed to identify the inputs. Generated
videos, extracted frames, contact sheets, and exploratory output should not be
committed here.
